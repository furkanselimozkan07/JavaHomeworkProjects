# Java Homework Projects

Java homework from my Computer Engineering courses at Eskişehir Technical University.

## Contents

| File | Description |
|---|---|
| `KnapsackProblem.java` | 0/1 knapsack solver: reads item weights/profits, builds a feasible knapsack and reports total weight and profit |

## Run

```bash
javac KnapsackProblem.java
java KnapsackProblem
```

Requires JDK 11 or later.
